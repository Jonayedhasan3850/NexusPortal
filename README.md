# NexusPortal

**A unified, university-verified platform connecting students, faculty, and employers with jobs, internships, and research opportunities.**

## Description

NexusPortal is a web-based career and research management system built to eliminate the fragmentation students face when hunting for opportunities across multiple platforms (LinkedIn, Bdjobs, ResearchGate, university mailing lists, etc.). It brings **job postings, internships, and academic research assistantships** into a single, filterable feed — backed by a strict **"University Verified"** layer that reduces fake postings and resume fraud.

Unlike traditional job boards, NexusPortal extends beyond employment to support **academic research collaboration**, allowing faculty to recruit and manage research assistants, track contributions, and coordinate lab work directly on the platform.

### Core Features

- **Unified Opportunity Dashboard** — one feed for jobs, internships, and research positions, filterable by skills, domain, location, and eligibility.
- **User Verification System** — ID/transcript upload and admin review to grant a "University Verified" badge.
- **Automated Resume Builder** — auto-generates industry-ready PDF resumes from a student's verified profile.
- **Research Collaboration Module** — dedicated workspace for faculty to manage labs, post RA openings, and track student contributions.
- **Application Tracking System (ATS)** — Kanban-style board for real-time application status tracking.
- **In-App Messaging & Interview Scheduler** — built-in chat and calendar integration to replace scattered email threads.
- **Admin Moderation Tools** — verification queue, posting review, reporting, and blacklist management.

### User Roles

| Role | Capabilities |
|---|---|
| Student / Job Seeker | Browse opportunities, apply, track applications, build resumes, join research groups |
| Employer / Industry HR | Post jobs/internships, review applicants, message candidates, schedule interviews |
| Faculty / Research Supervisor | Post research opportunities, manage research groups, track RA contributions |
| Administrator | Verify users, moderate postings, manage reports and blacklist, view analytics |

### Tech Stack

- **Frontend:** React (HTML5, CSS3, JavaScript)
- **Backend:** Node.js / Django
- **Database:** PostgreSQL / MySQL
- **Web Server:** Apache or Nginx
- **PDF Generation:** PDFKit / Puppeteer
